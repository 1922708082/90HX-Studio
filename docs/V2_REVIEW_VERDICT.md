## 二、我错了四处，它是对的（认错）

| #  | 我 V1 的判断                                    | 事实                                                                                                            | 谁对                                     |

## 四、必须修正的 5 处

### 1. 【硬伤】档位 3 的保底路线不成立

V2 第 5.2 节档位 3「A1-Win32LocalHttp」：

> C# 起一个 `HttpListener`，把 `postMessage` 降级为 WebSocket/EventSource，用系统浏览器 `--app` 打开**同一份** `hx_studio_6_1.html`

**实测：这份 HTML 里 `WebSocket` 0 次、`EventSource` 0 次、`chrome.webview` 3 次、`postMessage` 1 次。**

也就是说它**只会说 `window.chrome.webview`**。用系统浏览器打开时 `hasHost === false`，会直接落到 MOCK 分支——**看到的是演示数据，不是能用的程序**。

所以这条"终极兜底"实际需要：C# 侧 120 行 + **前端再写一套传输层**（双通道 + 自动探测 + 消息序列化）。这不是 1.5 人日，也没有解决"用户看到的是假数据"的问题。

**修正建议：直接删掉档位 3。** 改成：Runtime 缺失 → 内嵌 Bootstrapper 静默装 → 装不上（离线/被拦）→ 明确提示并给离线包链接 → 仍不行就退出，不放行。理由：Win10 22H2 / Win11 上 WebView2 缺失概率极低，为它养一套双传输层不划算。

### 2. F9 置信度不能靠论证升档

V2 把 F9 从「低」改成「**中→高（受控）**」。但 5.2 节的四步实测**一步都还没跑**。

它给的机制解释是成立的（双卡场景 GPU 输出在核显上，热重载矿卡不碰核显的 D3D 设备——这个洞察很关键，确实大幅降低风险）。但**置信度只能由实测升档，不能由论证升档**。

**修正建议：F9 保持「中，待 P0 实测」；跑完再写实测结论。** 否则 P0 门禁会失去约束力——反正"高置信"了，测不过也可以糊过去。

### 4. 三个数字没有来源

| 数字                                | 出处       | 问题                               |
| :-------------------------------- | :------- | :------------------------------- |
| 「双卡输出场景占矿卡玩家 **85% 以上**」          | 5.2 节    | 机制解释正确，但比例是编的                    |
| 「Win10 22H2 / Win11 覆盖率 **>97%**」 | Q10      | 无来源；这个数字直接决定"要不要内嵌 Bootstrapper" |
| 「视觉保留度 **95%**」                   | 5.2 档位 2 | 主观值当客观指标用                        |

**修正建议：三个都改成"估计值（待实测）"。** 尤其第 2 个——如果真实覆盖率是 88%，内嵌 Bootstrapper 就从"可选"变成"必选"。

### 5. 契约版本回退逻辑自相矛盾

V2 第 7.1 节：`app.init` 校验 `contractVersion`，不匹配时"**回退加载 exe 内置 HTML**"。

但如果 exe 内置的就是同一份 HTML，回退到内置版契约依然不匹配——**回退没有意义**。

**修正建议：把两种情况拆开**

- **契约不匹配** → 拒绝加载并报错（`CONTRACT_MISMATCH`），提示程序文件损坏或版本混装，走修复流程
- **磁盘文件 SHA-256 异常**（被篡改） → 回退到内置资源并记 `audit` 日志

## 六、它问的 6 个问题，我的答复（这是它要的输入）

| #  | 问题                                            | 答复                                                                                                                                                                                                                                      |
| :- | :-------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1  | `spoof.apply` 要不要带 MS-Hybrid / 覆盖补丁 / 热重载三个开关 | **不带。** 保持 `{ gpuSlot, targetName }`。理由：C# 侧 `ApplyGpuRenameAsync` 只改注册表，热重载由调用方做——所以 `spoof.apply` 内部固定执行「改名 → `SoftRestartGpuDriverAsync`」；覆盖已独立到 `overlay` 页，双卡已独立到 `dualgpu` 页，互不重叠。前端当前做法正确，不用改                                    |
| 2  | `dlss.deploy` 的 `options` 内部键名                | **锁定为 `{ optLevel, maxFrames, engine, preset, srMode }`**（对应 C# `InjectDlssG(gameDir, optVal, maxFramesVal, injectReFramework, proxyName, engineVal, presetVal, srModeVal)`）。它现在传的 `multiFrame` 语义等价于 `maxFrames`，**统一改名为 `maxFrames`** |
| 3  | 热点结温（hotspot）字段                               | **本期不加。** C# `GpuSensorSnapshot` 18 个字段里确实没有 hotspot。要加得改 NVML 查询与数据类，属于 P5 之后的事。前端不做是对的                                                                                                                                                |
| 4  | unlock 页为什么只有 3 款卡                            | **暂定 3 款是对的，但需要我核能力矩阵。** C# 里 `DeployNative40hxUnlock`、`DeployNative30hxUnlock` 存在，说明 30HX 也有一条原生部署链路（与 EFI 引导通道不是同一条）。70HX / 170HX 无 EFI 解锁路径。**P5 前我会把 6 款卡 × 各解锁路径列成矩阵，再定是否加第 4 个卡型**                                                |
| 5  | `window.close` 是退出还是最小化到托盘                    | **直接退出。** 因为省电守护是独立进程（`--powersave`）由计划任务拉起，不依赖 UI 存活。加托盘要多写一套 TrayIcon + 气泡 + 二次确认，收益低。**但临界事务期间（解锁/回滚/快照恢复）必须 `e.Cancel = true`**，这点 V2 已经写了                                                                                          |
| 6  | `update.state` 的 sha256 可不可信                  | **不可信，只验 sha256 等于没验。** 中间人可以同时替换文件与摘要。必须：① 内置公钥；② Release 附 `SHA256SUMS` 的 **detached 签名**；③ 先验签再验哈希；④ **删掉 `App.cs:439` 的 `ServerCertificateValidationCallback = { return true; }`**（这行不删，前面三条全白做）                                    |
