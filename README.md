# HX 家族多功能工具箱 v6.2

NVIDIA CMP 全系矿卡（30HX / 40HX / 50HX / 70HX / 90HX / 170HX）的一体化工作台：固件解锁、型号伪装、游戏覆盖、双卡调度、系统级省电、系统快照。

单文件免安装，纯原生 Windows 桌面程序（WPF + WebView2），前端页面与图标全部内嵌在 exe 内。

> 解锁会修改引导与驱动层配置，**有风险**。请先创建系统还原点；网游慎用（驱动层工具可能被反作弊识别）。

## v6.2 更新说明

这一版没堆新功能，主要把「说了但没做到」的地方补齐，并把界面上「看着能点、点了报错」的入口处理干净。

### 1. 固件解锁：不再有假成功

- **通道 C 改为本机引导**：此前选通道 C 会走 U 盘脚本路径，机器上没有 U 盘时依然回报「安装成功」。现在明确走本机 EFI 引导，缺条件就直说缺什么。
- **回滚结果如实上报**：回滚失败不再返回成功，BCD 备份缺失、ESP 写入失败会逐条列出。
- **安装前校验**：载荷缺失或哈希不符时安装直接终止，不会进入「装了一半」的中间态。
- **超时分级**：短任务 15 秒、中等 90 秒、长任务 600 秒；长任务超时后进入终态并提示「结果未知」，不会让按钮永远转圈。
- **操作串行化**：安装 / 回滚 / 恢复出厂共用一把组锁，重复点击得到「同类操作正在执行中」，不会并发写引导。

### 2. 双卡绑定（新增）

- 把指定游戏绑定到独显：写入 `HKCU\Software\Microsoft\DirectX\UserGpuPreferences` 的 `GpuPreference=2`
- **只替换 `GpuPreference` 段**，保留 `AppStatus`、`AutoHDREnable` 等已有设置，不会抹掉你原来的图形首选项
- 写入前后都回读校验；路径要求绝对路径 + `.exe` + 文件存在，任何字符串都不会进注册表
- 解绑即删除对应项，删除后回读确认

### 3. 恢复出厂（新增）

四步全部带回读校验，任何一步失败就整体报失败：

1. 恢复显卡型号名为出厂值（回读驱动描述确认，而不是看返回值）
2. 清理 PCIe 引导载荷并复位解锁状态
3. 删除 `pcie-unlocked.txt` / `compat-state.txt` 等状态文件
4. 移除省电计划任务（删除后重新查询确认）

执行前需要手动输入大写 `RESET`。

### 4. 快照回滚（新增）

- 新快照为 schema 2，额外记录 7 个可回滚的驱动类注册表值（`DriverDesc`、`AdapterString`、`AdapterType` 等）
- 回滚逐项写回并回读比对，失败项逐条列出
- **旧快照会明确拒绝回滚**：「该快照只记录了展示信息，无法用于回滚，请创建新快照」——不假装成功

### 5. 更新：直接读 GitHub Release

- 不需要自己写 `version.json`：默认读本仓库的 `releases/latest`
- 自动取 `tag_name` 当版本号、`body` 当更新说明、附件里的 `.exe` 当安装包
- **API 限流自动降级**：`api.github.com` 返回 403 时，改用 release 页面重定向取版本号、从 `expanded_assets` 片段取附件直链
- 有官方 `digest` 时强制 sha256 校验；降级链路拿不到摘要时，只允许 `github.com` 直链下载并校验 PE 头与体积，界面徽标显示「已下载 · 未校验哈希」而不是「校验通过」

### 6. 日志

- 读取移到后台线程，几十万行日志不再冻住界面
- 支持 `offset` 分页，「加载更多」真的能翻到更早的记录（此前只是把最近 200 行重复插一遍）
- 迟到的回执不再重复追加
- 复制日志复制的是**当前筛选结果**，不是全量

### 7. 界面

- 「看着能点其实不能点」的卡片去掉 hover 抬升与 pointer 光标
- 亮色主题下 9 处写死白边改为主题变量（此前设备树节点边框在白底上完全消失）
- 主按钮对比度 2.14:1 → 5.51:1（过 WCAG AA）
- 按钮执行中显示转圈，不再只有变暗
- 错误横幅可关闭，12 秒自动收起
- Tab 不再停在隐形下拉框上
- 模态框按 Esc 关闭时保留已输入的 RESET 草稿，只有点「取消」才清空
- 修掉每页底部多出一行「构建时按 pages/ 顺序注入 -->」的模板 bug

## 功能一览

- **硬件总览**：CPU / 主板 / BIOS / UEFI / Secure Boot / HAGS / 内存 / 显卡 / 显示器 / 硬盘 / 音频 / 网络 / 运行时间，实时传感器 + 3D 显卡拆解视图
- **固件解锁**：按卡型选择工具链，安装 / 回滚 / 诊断；安装成功后提示「完全关机断电 10 秒」
- **显卡伪装**：按架构过滤的目标型号列表（跨架构型号不会出现），改 `DriverDesc` 与适配项，支持恢复原名
- **游戏覆盖**：NVIDIA App 覆盖解锁、双缓存清理（含 `CefCache`）、弹性正则匹配
- **双卡调度**：扫描图形首选项、绑定 / 解绑程序到独显、HAGS 状态检测
- **动态省电**：空闲自动降压降频，检测到 GPU 负载立刻恢复；可注册开机自启系统任务（SYSTEM 权限），软件关掉照样工作
- **系统维护**：快照创建 / 回滚 / 删除，恢复出厂
- **日志**：分级过滤、关键词搜索、导出、复制当前筛选结果

## 安装与运行

1. 下载 Release 里的 `HX-Toolbox-*.exe`
2. 右键「以管理员身份运行」（改注册表与引导需要提权）
3. 首次运行会在 `C:\ProgramData\CMP90HX_Toolbox` 创建配置与工具目录

单文件分发，不需要安装 .NET 运行时；需要 WebView2 运行时（Windows 11 自带，Windows 10 若缺失会提示下载）。

## 常见问题

**Q：点解锁提示缺少管理员权限？**
右键 exe → 以管理员身份运行。程序不会自动提权。

**Q：解锁成功但显卡没变化？**
引导改动需要完全关机断电 10 秒再开机，普通重启无效（快速启动会跳过引导）。

**Q：伪装后设备管理器里显卡消失？**
v4.6.3 之后已停止修改系统 INF，不会再出现。若从旧版本升级上来，点「恢复原名」再重新扫描硬件。

**Q：省电开启后性能很低？**
省电是把 P-State 压到 P8。跑游戏或推理前点「恢复」或「软重启显卡驱动」。

**Q：检查更新提示 GitHub 接口限流？**
软件会自动降级为页面解析，仍能查到版本；若持续失败，可在更新页配置加速前缀。

**Q：更新包提示「未校验哈希」？**
说明当时 GitHub API 不可用，拿不到官方 sha256。软件只允许从 `github.com` 直链下载，并校验了 PE 头与体积。介意可稍后重试，API 恢复后会走完整校验。

## 从源码构建

```powershell
cd build_source
powershell -ExecutionPolicy Bypass -File build.ps1
```

构建流程：合并 `web/` 下的 CSS / JS / 页面片段 → 生成 `web/index.html` → 内嵌为资源 → 编译单文件 exe → 同步到 `D:\app` 与桌面。

构建门禁：契约审计（前端会发但后端未实现的命令必须为 0）、前端语法检查、C# `/warnaserror+`。

## 代码签名

仓库附带 `tools/sign-exe.ps1`：

```powershell
powershell -ExecutionPolicy Bypass -File tools/sign-exe.ps1
```

自签名证书只能证明文件未被篡改，其他机器仍会显示「未知发布者」。要消除 SmartScreen 提示需 CA 签发的 OV / EV 证书。**本项目的 Release 包未做商业证书签名**，请以本仓库 Release 页面为唯一可信来源，并核对 SHA-256。
