### 导航交互
- 点击导航项 → 右侧页面切换，带 **240ms 淡入 + 300ms 阻尼上浮** 转场
- 导航项用 `RadioButton` + `GroupName="NavGroup"` 实现单选互斥
- 悬停有浅灰底色反馈，光标为手型
- 侧边栏可滚动（低分屏不溢出）

## 六、启动动画（v3.0 精修版）

纯图标、全透明背景，无任何外框。148×148px 黑色 Squircle 图标，四阶段编排：

| 阶段 | 时间 | 效果 |
|---|---|---|
| ① 弹性涌现 | 0 → 1.18s | 五段式物理弹簧：0.68 → 1.07 → 0.965 → 1.018 → 1.00，比三段式更真实的阻尼振荡 |
| ② 落定光环 | 1.10s 起 | 一圈 1.6px 蓝色细环从 0.90 外扩到 1.42 并淡出 |
| ③ 双层流光 | 0.42s / 0.87s | 主流光（55px 宽、28° 倾斜）+ 副流光（26px 更淡），错开 0.45s 形成层次 |
| ④ 极光呼吸 | 1.18s 起 | 底部蓝色径向光晕 2.1s 周期呼吸；图标 1.0 → 1.018 极细微浮 |

辅助：图标 0.42s 柔淡入；DropShadow 52px 深空投影；1.2px 光致变色内高光描边。

## 七、代码结构

```
build_source/
├── src/
│   ├── MainWindow.xaml      # 界面（图吧风格骨架 + 9 页面）
│   ├── App.cs               # 生命周期 / 控件绑定 / 事件 / 导航 / 状态刷新
│   ├── NativeCore.cs        # 底层硬件引擎（注册表 / INF / BCD / EFI / 文件释放）
│   ├── SystemDetector.cs    # 硬件探测（WMI / 注册表 / 传感器）
│   ├── SplashWindow.xaml    # 启动动画
│   ├── SetupWindow.xaml     # 安装引导窗
│   └── AssemblyInfo.cs
├── Packager.cs              # 明文资源打包器（ZIP，无加密）
├── pack.ps1                 # 打包 assets.zip
├── build.ps1                # 编译 90HX Studio.exe
├── render.ps1               # UI 无头渲染测试
├── render_splash.ps1        # 启动动画渲染测试
├── RenderAllTabsV2.cs       # UI 渲染器
├── RenderSplash.cs          # 启动动画渲染器
├── docs/                    # 文档（本目录）
├── mining_unlock_toolkit/   # 各型号官方解锁工具黄金备份
└── _backup_refactor_20261014/  # 重构前全量备份
```

### 构建命令

```powershell
# 1. 打包明文资源包（生成 D:\app\assets.zip）
powershell -ExecutionPolicy Bypass -File "D:\app\build_source\pack.ps1"

# 2. 编译单文件免安装程序（生成 D:\app\90HX Studio.exe）
powershell -ExecutionPolicy Bypass -File "D:\app\build_source\build.ps1"

# 3. UI 渲染验证（输出 PNG 供排版检查）
powershell -ExecutionPolicy Bypass -File "D:\app\build_source\render.ps1"
powershell -ExecutionPolicy Bypass -File "D:\app\build_source\render_splash.ps1"
```

## 八、代码规范（硬约束）

1. **C# 5.0 语法**：编译器为 .NET Framework 4.x `csc.exe`，严禁 `$"..."` 插值、`?.`、`nameof`、自动属性初始化器等 C# 6+ 特性
2. **UI 零依赖**：不引入任何第三方 UI 库，纯原生 XAML 模板
3. **控件绑定必须判空**：所有 `FindName` 结果使用前判 null，防止界面调整后空引用崩溃
4. **写操作必须校验管理员权限**：`NativeCore.IsAdmin()` + `EnsureAdminPrivilege()` 守卫
5. **硬件安全红线**：修改 BCD / ESP 前必须备份；提供一键还原路径
6. **禁止 reintroduce 加密**：资源一律明文 ZIP；禁止 AES / XOR / Base64 字符串混淆
