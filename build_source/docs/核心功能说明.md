# 90HX Studio · 核心功能说明

> 版本：v3.0（全开源重构版）
> 定位：NVIDIA CMP 矿卡（30HX / 40HX / 50HX / 90HX）硬件解锁与调优套件
> 形态：单文件绿色免安装 Windows 桌面程序（WPF / .NET 4.x）

---

## 一、这是什么

CMP 系列是 NVIDIA 2021 年推出的「纯挖矿」显卡，与游戏卡同核心（如 90HX = GA102、50HX = TU102、40HX = TU106、30HX = TU116），但 NVIDIA 在**固件与驱动双层**施加了限制：

| 限制 | 表现 |
|---|---|
| 算力熔断 | CUDA/OpenCL 算力被压到极小比例（90HX 推理 230 t/s，实际可达 3700 t/s） |
| 图形屏蔽 | 驱动将矿卡标记为 "processing accelerator"，不提供 3D 渲染 |
| PCIe 降速 | Gen1.1 且通道数被砍（50HX 仅 x4） |
| 型号伪装屏蔽 | 设备管理器显示 CMP 型号，游戏覆盖/录屏被拉黑 |

本软件就是把上述限制**逐层解开**，并处理解锁后的一整套系统适配（显卡改名、跨卡输出、游戏覆盖、帧生成注入、电源调优）。

## 二、九大功能模块

### 1. 硬件信息（图吧工具箱风格看板）
- 图吧工具箱 1:1 硬件资产面板：型号信息、系统信息、运行时长三卡片
- 详细信息表：主板 / 处理器 / 内存 / 显卡 / 显示器 / 硬盘 / 声卡 / 网卡
- 实时传感器：核心温度、风扇转速、功耗（进度条可视化）
- 数据来源：WMI + 注册表 + nvidia-smi，全部本地探测，无联网

### 2. 显卡型号伪装（设备管理器 / DirectX / NVIDIA App 三端同步）
- 将矿卡在设备管理器中伪装为对应 GeForce 游戏卡：
  - 90HX → RTX 3080（可改 3070 Ti）
  - 40HX → RTX 2060 SUPER
  - 50HX → RTX 2080 Ti
  - 30HX → GTX 1660 SUPER
- 同步写入位置（这是「改了不生效」的关键，全部覆盖才会生效）：
  - `Control\Class\{4d36e968-...}` 驱动类：`DriverDesc` / `AdapterString` / `ChipType`
  - `Control\Video\{GUID}\0000` 显卡服务项
  - `Services\nvlddmkm\Video`
  - `SOFTWARE\Microsoft\DirectX` 适配器描述缓存
  - **`C:\Windows\INF\oemXX.inf` 驱动定义文件**（设备管理器显示名的真正来源，动态探测当前 INF 而非写死路径）
  - `DriverStore\FileRepository` 内的驱动副本
  - NVIDIA App 本地 `SHIM.json` 缓存
- 关键 3D 图形键值注入：`AdapterType=1` / `EnableMsHybrid=1` / `RMDisableTcc=1` / `D3DMappingLayerEnable=1`
- 改完后通过 `pnputil /restart-device` 对显卡实例做**真实 PnP 热重载**（不是只杀 dwm.exe），设备管理器立即刷新

### 3. NVIDIA App 游戏内覆盖解锁（ShadowPlay）
- 新版 NVIDIA App 通过云端硬件白名单对 CMP 卡施加限制，导致 Alt+R 性能浮窗、Alt+Z 录屏无法开启
- 直接改写 NVIDIA App 前端 `main.*.js`，解除 `ShadowPlaySupported` 与云端 `overallState` 判定（改前自动备份 `.bak`）
- 自动定位 NVIDIA App 安装路径，改完重启相关进程并清空 CEF 缓存

### 4. 全系矿卡解锁矩阵（核心）
**双模式互斥：**

| 模式 | 作用 | 适用场景 |
|---|---|---|
| 🎮 图形与算力双轨解锁 | Gen2 x16 + 型号伪装 + 3A 游戏 Direct3D 渲染 + MS-Hybrid 跨卡输出 + P0 满载频率 | 想玩游戏 / 跑图形应用 |
| ⚡ 固件级算力满血解锁 | 击穿固件 SEC2/PLM 锁，llama 推理提速约 16 倍，零显示开销 | 纯 AI 推理 / 挖矿 |

**四种安装通道（按主板选）：**

| 通道 | 方式 | 适用 |
|---|---|---|
| A | 现代 UEFI 独立启动项：部署 ESP 后建独立解锁启动项（不劫持 Windows 引导，失败自动兜底），解锁文件已签名 | 新主板（推荐） |
| B | 老主板 UEFI Shell 链式启动（同 A 的独立启动项方案） | 华南 / 精粤 / X79 / X99 |
| C | 驱动 Hook，绕过测试签名 | 老卡 / 无法改 EFI |
| D | FAT32 U 盘免安装直启（BOOTX64.EFI + 自动 startup.nsh） | 不想动硬盘 / 排查用 |

> 通道 A/B 的独立启动项方案说明：解锁文件（含签名）部署到 ESP `\EFI\NVPermissive\`，
> 通过 `bcdedit /copy {bootmgr}` 创建独立启动项并置顶，Windows 启动管理器保持官方原样；
> 解锁失败时固件自动落到第二项正常进系统，可从【一键清理引导冗余项】随时还原。
> Secure Boot 开启时：在 BIOS 密钥管理里把两个解锁 EFI 追加进 db，或直接关闭 Secure Boot。

**辅助操作：** 一键还原官方出厂、BCD 引导自检与修复、⚡ 让 U 盘优先启动（关快速启动 + 建独立 UEFI 启动项置顶）

**多卡支持：** 自动枚举全部矿卡，支持单卡精准操作与全机混合矩阵批量解锁；每张卡独立记录架构、PCI ID、Class 子键、伪装目标与当前状态。

### 5. 双卡调度（MS-Hybrid 跨卡渲染呈现）
CMP 卡没有视频输出口，必须靠核显或亮机卡出画面：
- 架构图解 + 三避坑法则（显示器接核显口 / BIOS 开 iGPU Multi-Monitor / 游戏无边框窗口化）
- 自动写入跨卡渲染注册表（`EnableMsHybrid`、`DirectXUserGlobalSettings=HighPerfAdapter=...`）
- 双卡状态实时探测与刷新

### 6. DLSS 3 帧生成
- 内置 DLSS-G for SM86 运行库（`version.dll` + `dlssg_sm86.ini`）
- 一键注入指定游戏目录，在 RTX 30 系（GA102）等架构上强制开放帧生成
- 4 个国内镜像源测速 + 失败自动回退到内置运行库
- 本地版本检测、已注入标记、卸载还原

### 7. 硬件与电源
- HAGS（硬件加速 GPU 调度）一键开启
- Windows 卓越性能 / 高性能电源计划切换
- TGP 功耗上限与风扇自定义曲线（联动调优）
- 显卡驱动快捷软重启（PnP 级）

### 8. 审计日志
- 深色极客终端风格（`TerminalLogBoxStyle`，防误触变白）
- 全部底层操作可追溯：注册表写入、INF 修改、BCD 变更、文件释放
- 一键清空 / 复制到剪贴板

### 9. 赞赏与支持
- 微信 / 支付宝收款码**以明文资源形式内嵌于 EXE**，单文件分享到任何电脑都能直接扫
- 加载用内存流 + 位图冻结双保险，零外部依赖

## 四、前置条件（BIOS 必设）

| 设置项 | 要求值 | 原因 |
|---|---|---|
| Secure Boot | **关闭** | EFI 解锁固件未签名 |
| CSM | **关闭**（纯 UEFI） | 固件才能看到启动项 |
| Above 4G Decoding | **开启** | 载荷缓冲区在 4GB 以上 |
| Fast Boot | **关闭** | 否则 UEFI 步骤被跳过 |
| Resizable BAR | Auto / 开启 | 配合 Above 4G |
| PCIe 插槽速率 | **Gen2**（不要 Auto） | 50HX/40HX 链路训练关键 |
| 系统盘 | GPT + UEFI 引导 | 通道 A/B/D 依赖 |

## 六、已知限制

1. **50HX 的 RT 光线追踪核心物理熔断**，软件无法解锁（SM/Tensor 可满血，RT 执行器硬件断开）
2. **50HX PCIe 通道物理为 x4**，跨卡游戏带宽是瓶颈（赛博朋克 2077 实测约 25 FPS）
3. **40HX 解锁是"补票"不是"换命"**：12 款游戏 1080P 平均帧 +15%、低帧 +10%
4. **90HX 游戏是赠品**：无输出口、Gen1 ×16、必须配补丁驱动
5. **EFI 解锁不持久**：每次重启失效，靠启动项每次开机重跑；40HX/50HX Windows 安装版写启动项实现自动化
6. **Windows 更新 / 双系统改动 / BIOS 变更 / 安全软件**可能让启动项失效，大改动后需复查
7. **Linux 补丁方案**强依赖 NVIDIA Open 610.43.03 / 580.159.03；Windows 补丁器跟随官方新版
