CMP 90HX 解锁启动项套件（ESP 固件启动项方式）
=====================================================

一、这是什么
-----------------------------------------------------
把解锁流程做进系统自己的启动项里，不需要 U 盘、也不劫持
{bootmgr}。开机时固件先跑独立启动项 "CMP 90HX Unlock
(EFI Shell)"，它启动 EFI Shell 并自动执行 startup.nsh：

    startup.nsh 干的事 = 替你敲这两行官方命令：
        1) NVPermissiveEFI.efi windows   （解锁，要等一会）
        2) bootmgfw.efi                  （自动链启 Windows）

和官方 readme 的区别只是：命令由脚本自动敲，不用手动输入。
Windows Boot Manager ({bootmgr}) 完全不动，保持官方状态，
所以这套方案不可能把系统搞的开不了机——最坏情况就是没解锁。

二、文件清单
-----------------------------------------------------
  NVPermissiveEFI.efi        解锁主程序（202610150835 官方最新版）
  shellx64.efi               EFI Shell（pbatard edk2-stable202602）
  startup.nsh                自动敲命令脚本（核心，CRLF，纯 ASCII）
  【右键管理员运行】安装90HX解锁启动项.bat   安装器 v2（免挂载版）
  【右键管理员运行】还原移除90HX解锁项.bat   还原（纯 ASCII）
  【右键管理员运行】检查引导状态.bat         引导状态检查（只读）
  【右键管理员运行】清理僵尸启动项.bat       僵尸启动项清理
  install-v2.ps1 / esp-helper.ps1           内部辅助（被上面 bat 引用，别动）
  BCD_Backup\                安装时自动生成的 BCD 备份

  命名规则：.bat 的【文件名】可以是中文（安全），但 .bat 的
  【内容】必须永远保持纯英文 ASCII —— 往内容里粘中文会碎行。
  两个 .ps1 是内部辅助，英文名保留（bat 要引用它们）。
  整个文件夹要一起搬，别单独拷某个文件。

三、使用步骤
-----------------------------------------------------
第 0 步（已完成）：检查引导状态.bat 已跑过，确认了
  {bootmgr} 官方未被劫持、ESP 无残留文件；
  清理僵尸启动项.bat 也已跑过，12 个旧实验残留项已清除。

第 1 步：确认 BIOS 里 Secure Boot 已关闭（未签名的 EFI 会被拒跑）。

第 2 步：右键【右键管理员运行】安装90HX解锁启动项.bat
  -> 以管理员身份运行 -> 看到 "Install v2 finished" 后重启。
  （这是 v2 免挂载版：不走 mountvol，直接通过卷路径写 ESP，
  之前 v1 卡住就是卡在 mountvol 上。）

四、重启后应该看到什么
-----------------------------------------------------
  黑屏 -> EFI Shell 界面 -> 打印解锁日志（等一会，别断电）
  -> 自动进 Windows。
  注意：Shell 启动时可能显示一行倒计时
    "Press ESC in N seconds to skip startup.nsh ..."
  千万不要按 ESC（按了就等于跳过自动脚本），
  什么都不按等它自己走完，或按任意非 ESC 键跳过等待。
  进系统后验证（管理员 CMD / PowerShell）：
      nvidia-smi --query-gpu=pcie.link.gen.current,pcie.link.width.current --format=csv
  应看到 2 / 16（PCIe Gen2 x16）。

五、出问题怎么办
-----------------------------------------------------
Q1: 重启后直接进 Windows，没看到 Shell 界面？
A:  启动顺序没生效。开机按启动菜单键（华硕 F8 / 微星 F11 /
    其他多为 F12），手动选 "CMP 90HX Unlock (EFI Shell)"。
    能手动选说明启动项建好了；想自动第一就重跑安装脚本，
    或把 check-boot-state.bat 的输出贴给助手。

Q2: 停在 EFI Shell，没有自动跑？
A:  startup.nsh 没触发。手动敲官方两行：
        NVPermissiveEFI.efi windows
        bootmgfw.efi
    把屏幕内容拍给助手排查。

Q3: 解锁跑过了，但 GPU-Z / nvidia-smi 还是 Gen1？
A:  1 完全断电（拔电源）重开——解锁在显存里，掉电就丢；
    2 换 PCIe 槽；3 BIOS 关 ASPM；4 确认装了魔改驱动。

Q4: 想彻底不用了？
A:  右键管理员运行【右键管理员运行】还原移除90HX解锁项.bat。

六、血的教训：编码
-----------------------------------------------------
  .bat 文件是【纯 ASCII 英文】的，这是故意的——
  中文写进 .bat 会因控制台码页（GBK/UTF-8）不匹配而碎行，
  轻则乱码，重则命令被啃碎（mountvol 变 tvol）、路径全废。
  所以：
    1. 绝对不要往 .bat 里粘中文
    2. 也不要用记事本等编辑器"修复"后另存（会改编码）
    3. 想写中文说明，写在本 txt 里，别写进 .bat

七、重要提醒
-----------------------------------------------------
1. 解锁状态在显存里：完全断电 / 冷启动后必须重跑；Windows
   里点重启、睡眠唤醒不需要重新解。
2. 驱动：EFI 解锁只是前半段，Windows 里还要装魔改驱动。
   - 616.92（alist 最新）：修了 grGetRTCoreCount，光追可用，
     但编解码（NVENC/NVDEC）异常、少数 OpenGL 场景性能异常
   - 616.56（你本地已有）：无光追、无编解码，但解锁了功耗墙
     （nvidia-smi -pl 300 可拉到 300W，注意还有频率墙电流墙）
   - E 盘 U 盘里 配套工具与补丁\NVIDIA-patcher\windows.bat
     是给 CMP 打 3D 渲染补丁的标准工具
3. 安装脚本会把 ESP 挂载到 S: 方便检查，用完可 mountvol S: /D。
4. 安装脚本可重复运行（自动清理旧解锁项再重建）。
