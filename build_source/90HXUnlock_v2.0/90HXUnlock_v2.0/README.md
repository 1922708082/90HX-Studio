# CMP 90HX Windows 一键免 U 盘解锁工具 v2.0 (Compat 直启双保险版)

**CMP 90HX (GA102) 矿卡 ➔ 完整计算算力 + 3D 图形渲染 + PCIe Gen2 + 免 Shell 秒进 + 原生双保险引导**

本工具在原有方案基础上全面重构升级至 **v2.0**，融合了最新的 NVPermissive Compat 二进制补丁与 `{bootmgr}` 接管架构。彻底消除了传统 UEFI Shell 的开机黑屏等待、多 ESP 分区冲突拒载以及部分主板过滤第三方固件启动项的顽疾。

---

## 一、v2.0 核心技术与升级亮点

1. **免 UEFI Shell 直启（开机提速 2~5 秒）**：
   - 采用补丁版 `NVPermissiveCompat.efi`，默认直接运行 Windows 解锁模式，不再依赖中间层 `Shell.efi` 和 `startup.nsh`；
   - 开机无黑底黄字命令行闪烁，直接秒进系统。
2. **官方原生双保险引导机制（永不卡黑屏变砖）**：
   - 安装时接管官方 `{bootmgr}` 启动项，并在第二顺位自动生成官方原生 `Windows Boot Manager (Backup)`；
   - 固件优先执行解锁链；若遇到硬件未初始化、换卡或用户按 Esc 退出，主板 UEFI 会按照规范平滑回落至第二顺位，**100% 确保能正常进入 Windows 原生系统**。
3. **多 ESP 分区 / PE U 盘兼容增强（解决拒载 Bug）**：
   - 修复了原版 DirectBoot 必须“恰好 1 个 Windows 分区”的判定 Bug；
   - 在多硬盘、双系统、插着 Windows 安装盘或 PE 盘的环境下，均能稳定链式启动，杜绝 Refused 报错。
4. **状态快照与完整性校验**：
   - 每次安装前自动校验核心固件的 **SHA256 哈希**，防止坏文件写入；
   - 自动在 `snapshots/` 目录下备份当前 NVRAM / BCD 引导状态快照，安全可追溯。
5. **极简操作与双击自提权**：
   - `manual_install.bat` 与 `manual_uninstall.bat` 均支持双击自动申请管理员提权；
   - 内置防重复安装、防重复卸载以及旧版 40HX/90HX 引导冲突自动清理。

## 三、使用前准备（BIOS 设置）

开机按 `Del` 或 `F2` 进入主板 BIOS，确保以下设置生效：
1. **Above 4G Decoding** ➔ 设为 **Enabled**（必须开启）
2. **Secure Boot** ➔ 设为 **Disabled**（必须关闭，否则无法加载自定义固件）
3. **CSM (兼容支持模块)** ➔ 设为 **Disabled / 关闭**（纯 UEFI 模式）
4. **Resizable BAR** ➔ 建议开启（Auto / Enabled）

## 四、安装与日常使用流程

1. **一键安装 90HX 解锁**：
   - 打开本目录，双击运行 `manual_install.bat`（或右键【以管理员身份运行】）；
   - 脚本会自动校验文件、备份引导快照、部署固件并重构双保险引导链；
   - 安装完成后控制台会提示成功。
2. **完全关机（重要！）**：
   - 点击开始菜单 ➔ **关机**（**务必完全关机掉电，不要点"重启"**）；
   - 关机后等待主机指示灯完全熄灭、电源彻底断电 10 秒以上。
3. **开机生效**：
   - 重新按下主机电源开机，开机会秒进系统（无需 Shell 等待）。
4. **验证与安装驱动**：
   - 进入 Windows 后打开 GPU-Z，确认 90HX 的总线接口是否显示为 **`PCIe x16 2.0`**（解锁成功）；
   - 首次使用请双击运行【`下载专用驱动.bat`】下载并安装配套的 616.56 GA10x 魔改驱动。

## 五、卸载与恢复原生引导

当您不再使用 CMP 90HX 或换回普通显卡时：
1. 双击运行 `manual_uninstall.bat`（或右键【以管理员身份运行】）；
2. 脚本会自动还原官方 `{bootmgr}` 路径、删除备份项并清理 ESP 分区中的解锁文件；
3. 下次开机将 100% 恢复微软官方原生引导，无任何残留。
