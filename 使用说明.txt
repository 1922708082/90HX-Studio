【产品定位与设计规范】
本软件为专为 CMP 90HX (GA102 架构) 游戏与算力调优打造的极速整合控制中心。
软件采用现代高质感简约白界面 (Minimalist Light UI)，视觉清爽利落、护眼舒适，
底层核心与驱动二进制固件均经过 AES-256-CBC 军事级加密打包，安全防呆、原生双保险。

--------------------------------------------------------------------------------
一、八大核心整合功能模块
--------------------------------------------------------------------------------

1. 显卡型号深度伪装 (CMP 90HX ⇄ NVIDIA GeForce RTX 3080)
   - 彻底解决游戏、跑分软件因检测到 CMP 矿卡设备号而导致的闪退、弹窗警告或锁死画质。
   - 同步修改系统显卡驱动类 (Class)、设备管理器友好名称 (Enum PCI)、DirectX 适配器描述、
     底层系统 INF (C:\Windows\INF 及 DriverStore) 与 NVIDIA App 本地 SHIM 缓存。
   - 修改前自动生成原生注册表备份，支持随时一键无损还原出厂名称。

2. NVIDIA App 游戏内覆盖 (In-Game Overlay) 强制解锁
   - 绕过新版绿色 NVIDIA App 云端 PCI ID 白名单检测机制。
   - 完美解锁游戏内快捷键功能：
     • [Alt + R] ：实时呼出/隐藏显卡性能监控悬浮窗 (FPS 帧率、核心温度、频率、功耗等)。
     • [Alt + Z] ：呼出控制台总界面 (无损高清录屏、即时重放抓拍、游戏滤镜、音频设置)。
     • [Alt + F1]：快速保存精彩瞬间无损截图。
   - 打补丁前自动备份原始 main.*.js 脚本，支持随时一键完全复原。

3. PCIe 多模式速率安全解锁 (独家支持 3 种解锁模式自由切换)
   - CMP 90HX 出厂硬件被英伟达强制锁在 PCIe 1.1 速率。本工具在 UEFI 阶段临时改写寄存器，
     开机提速至 PCIe Gen2 x16，大幅提升 3A 游戏显存交换带宽。
   - 多模式灵活适配：
     • 模式 1 (免 Shell 极速直启双保险版，默认推荐)：秒进系统无黑屏等待，内嵌备用引导兜底。
     • 模式 2 (UEFI Shell 兼容脚本模式)：针对精粤、华南金牌等特殊 BIOS 主板具备极佳兼容性。
     • 模式 3 (免安装 U 盘直启 / 现场诊断救援盘)：不触碰本地硬盘 ESP 分区，一键制作自启 U 盘。
   - 防小白重复安装机制：每次安装或切换模式前，自动执行原子级防呆清理，绝不残留多余引导项！

4. 双卡调用方案 (MS-Hybrid 跨卡渲染拓扑与独占调度)
   - CMP 90HX 未配备物理视频输出接口，必须通过 CPU 核显 (Intel UHD / AMD Radeon) 输出画面。
   - 本模块采用 Windows Direct3D 跨适配器呈现技术 (CASO)，由 90HX 满血负责游戏 3D 渲染，
     并将成品画面经由 PCIe 总线极速拷贝至核显进行无损高刷输出。
   - 支持一键全盘扫描并绑定常见 3A 游戏独占 90HX，避免游戏误调用核显导致卡顿。

5. DLSS 3 帧生成 (Frame Generation) 注入辅助 (RTX 30 系列专属)
   - 基于 DLSSG for SM86 运行库，向 D3D12 游戏注入代理层，在 90HX 上强制开启帧生成选项。
   - 支持 4 档优化内核 (Optimized 0~3) 与最大生成帧率 (2X/3X/4X/6X) 动态调节。
   - 【RE 框架专属选项】：针对《怪物猎人: 荒野》《生化危机》《龙之信条》等卡普空 RE 引擎游戏，
     提供一键附带注入 RE 框架代理 (dinput8.dll) 选项，彻底解决部分游戏启动闪退问题！

6. DLSSG 运行库多镜像云端自动更新系统
   - 对接官方开源项目 (sdli1995/dlssg_for_sm86)，支持实时在线版本比对。
   - 内置 4 大高速镜像源线路：
     ① Ghproxy 高速镜像源 (推荐国内网络，首选加速通道)
     ② jsDelivr 全球 CDN 源 (极速同步，低延迟)
     ③ FastGit 镜像加速源 (备用线路)
     ④ GitHub 官方直连源 (海外网络或直连环境)
   - 支持一键拉取最新运行库，并自动同步替换当前选中游戏目录中的补丁文件！

7. 图吧工具箱实用硬件调试工具集
   - 快捷软重启显卡驱动：一键重启 DWM 显示子系统，显卡改名或调优后无需重启电脑。
   - 硬件加速 GPU 计划 (HAGS)：一键查询与切换，大幅降低双卡跨卡复制延迟。
   - Windows 卓越性能电源模式：一键激活并应用，防止显卡在待机节能下 PCIe 降速。
   - 集成 Windows 设备管理器、DirectX 诊断工具 (dxdiag)、NVIDIA 原生控制面板快捷直达。

8. 实时硬件监控传感器与 GPU 负载压力测试
   - 实时采集 GPU 核心温度、风扇转速占空比、整卡功耗、显存占用、核心利用率与时钟频率。
   - 提供 GPU 动态负载唤醒测试，一键唤醒 PCIe Gen2 全速状态。

--------------------------------------------------------------------------------
二、推荐使用步骤 (初次调优)
--------------------------------------------------------------------------------

1. 显卡与覆盖优化：
   打开控制中心，点击顶部【⚡ 一键最优配置】，程序将自动完成显卡改名 RTX 3080、
   解锁 NVIDIA App 游戏覆盖并部署模式 1 PCIe Gen2 解锁。

2. PCIe 解锁生效：
   配置完成后，请将主机执行【完全关机】（注意：是关机而非重启），断电拔插头 10 秒后重新开机，
   主板即可完成显卡寄存器提速重载。开机后打开控制中心查看 PCIe 链路状态即为 PCIe x16 2.0！

3. 双卡与 3A 游戏：
   在【双卡调用方案】中点击【一键全盘扫描并绑定常见游戏】，确保游戏启动时强制调用 90HX 渲染。
   在【DLSS 3 帧生成】中选择游戏主程序目录，根据需要勾选【RE 框架】后一键注入，畅享 3A 高帧！

--------------------------------------------------------------------------------
三、安装与卸载指南
--------------------------------------------------------------------------------

- 使用：直接双击运行【CMP 90HX 控制中心.exe】即可使用（绿色免安装单文件版）。
        内置原生 UAC 管理员提权与核心加密固件，开箱即用，无需安装。
- 卸载/还原：在控制中心内点击【一键彻底还原官方原生引导】及【恢复出厂 CMP 90HX 原名】，
        即可瞬间无残留复原系统环境。

--------------------------------------------------------------------------------
四、重要技术提示
--------------------------------------------------------------------------------
1. 安全启动 (Secure Boot)：安装 PCIe 开机解锁前，请务必在主板 BIOS 中关闭 Secure Boot (设为 Disabled)。
2. 显示器线缆连接：由于 90HX 无输出接口，显示器线缆 (HDMI/DP) 务必插在主板核显接口上。
